# Python SDK

The official Python SDK for Mokra mock servers and MockWorld Tests.

## Installation

```bash
pip install mokra
```

## Quick Start

The `mokra` package provides an `observe()` context manager that intercepts
HTTP calls made by your code and records what happened.

```python
from mokra import observe
import requests

with observe() as world:
    response = requests.post(
        "https://api.stripe.com/v1/charges",
        auth=("sk_test_anything", ""),
        data={"amount": 5000, "currency": "usd"}
    )

# Print what happened
print(world)
```

### Environment variables

```bash
export MOKRA_API_KEY="mk_live_..."
```
## Observing HTTP Calls

### Basic usage

Wrap your code in `observe()` to record all HTTP interactions:

```python
from mokra import observe
import requests

with observe() as world:
    # Your code makes normal API calls
    response = requests.post(
        "https://api.stripe.com/v1/charges",
        auth=("sk_test_anything", ""),
        data={"amount": 5000, "currency": "usd"}
    )

# See what happened
print(world)
# Outputs a table of service, method, URL, and status code
```

The `observe()` context manager patches `requests` and `httpx` at the HTTP
adapter layer. Your code runs normally; mokra just records every request and
response.

### Accessing recorded data

```python
with observe() as world:
    requests.post("https://api.stripe.com/v1/charges", ...)

for service_name, service in world.services.items():
    print(f"Service: {service_name}")
    for i, req in enumerate(service.requests):
        status = service.responses[i]["status_code"]
        print(f"  {req['method']} {req['url']} -> {status}")
```
## Generating Tests

After observing interactions, generate pytest stubs automatically:

```python
from mokra import observe, generate_tests
import requests

with observe() as world:
    requests.post(
        "https://api.stripe.com/v1/charges",
        auth=("sk_test_anything", ""),
        data={"amount": 5000, "currency": "usd"}
    )

# Generate pytest code from the observations
test_code = generate_tests(world)
print(test_code)

# Or write directly to a file
generate_tests(world, output_path="tests/test_stripe.py")
```
## Example: pytest integration

```python
# test_stripe.py
from mokra import observe
import requests

def test_charge_is_recorded():
    with observe() as world:
        requests.post(
            "https://api.stripe.com/v1/charges",
            auth=("sk_test_anything", ""),
            data={"amount": 5000, "currency": "usd"}
        )

    assert "stripe" in world.services
    assert len(world.services["stripe"].requests) == 1
    assert world.services["stripe"].requests[0]["method"] == "POST"
```
## Example: Testing LangChain agents

```python
from mokra import observe
from langchain.agents import AgentExecutor

def test_support_agent():
    with observe() as world:
        agent = AgentExecutor(...)
        agent.invoke({"input": "Refund order #1234"})

    # Check what services the agent called
    print(world)
    assert "stripe" in world.services
```
## API Reference

### `observe()`

Context manager that intercepts HTTP calls and records them.

```python
with observe() as world:
    # your code here
    pass
```

Returns a `WorldState` object.

### `WorldState`

Tracks all observed HTTP interactions.

| Attribute | Type | Description |
|-----------|------|-------------|
| `services` | dict[str, ServiceState] | Map of service name to state |

Printing a `WorldState` renders a table of all observed requests.

### `ServiceState`

State for a single service.

| Attribute | Type | Description |
|-----------|------|-------------|
| `name` | str | Service name (e.g. "stripe") |
| `requests` | list[dict] | Recorded requests (method, url, headers, body) |
| `responses` | list[dict] | Recorded responses (status_code, headers, body) |

### `generate_tests(world, output_path=None)`

Generate pytest test stubs from observed interactions.

| Parameter | Type | Description |
|-----------|------|-------------|
| `world` | WorldState | Observed interactions |
| `output_path` | str or None | Optional file path to write tests |

Returns the generated test code as a string.
